# 客户充值明细（逐笔流水）

入口：账本分析 → 客户充值明细。

列表每行直接对应 customer_recharge 的一笔原充值记录，包含充值时间、充值单号、客户代码/名称、充值金额、支付方式、状态、操作人和备注。同一客户多次充值分别显示，不再先展示客户余额/累计金额表；无充值记录的客户不生成占位行。移除“充值”“明细”行操作及本页新增充值入口。

搜索支持：关键词（客户代码/名称、充值单号、备注）、客户、单号、支付方式、状态、北京时间日期区间、金额上下限。查询/回车提交条件；重置清空筛选；刷新沿用已提交条件；服务端分页使用稳定时间与ID排序。客户列表带customerId的链接可直接筛选该客户，重置可返回全部。

金额合计是筛选记录的金额；已确认入账金额单独统计，未确认/取消记录不算已确认入账。查询不改客户余额，不将货盘退款当作充值。无操作人记录显示“系统/未记录”，不推断真实渠道。

导出按钮明确为“导出本页明细”，仅下载当前表格显示行；不再导出客户汇总数据。保留 budget_credit.view / budget_credit.export 权限；原充值写入接口和既有数据未删除。本次无需数据库迁移。

接口：GET /customers/recharges，采用 RechargeRecordQueryDto 验证，组合条件对列表、计数及汇总一致生效，日期包含结束日全天；非法金额、反向日期及超限参数不静默放宽筛选。
