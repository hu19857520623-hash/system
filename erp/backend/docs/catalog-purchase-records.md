# OMS货盘采购记录

入口：ERP → 货盘库存 → OMS货盘采购记录。货盘池和货盘持有都可打开；原货盘持有行内的购买明细复用此入口并预置对应客户和SKU。

支持按客户代码/名称、SKU/商品名称、采购单号、采购日期（北京时间）和状态组合筛选，服务端分页，每页最多200条，不再只读取前100条。

展示客户、商品、采购时间、成交价格档位、原采购数量、原成交单价、原采购金额、已审核退回数量、净采购数量和采购状态。详情包含采购前后当时余额、退回金额、净采购金额及已审核退款流水。

数量与成交金额读取原 oms_catalog_order，不使用当前售价；退回从已保存且验证通过的ERP退款回执分摊统计。原采购单不被改写，持有归零仍可查询。净采购数量=原采购数量−已审核退回数量，不等同于当前可用库存（出库也会减少可用量）。待审核、驳回、撤销申请不算已退回。退款依据不完整时保留原采购显示，将退回和净值标为待核对，不假报零退款。

汇总仅表示筛选范围的原始采购笔数、数量与金额，未扣除退款。商品名称取当前主数据作辅助识别，成交数量、价格与档位取历史原单。

权限：pricing.view、inventory_query.view、inventory_query.detail、logistics_wh.view任一可读。全部为只读查询，不新增订单、不修改库存或余额。不需要数据库迁移。
