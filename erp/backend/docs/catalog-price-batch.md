# 四档价格批量上传与修改

入口：ERP → 货盘库存 → 货盘池 → 四档价格批量上传 / 修改。需要 pricing.set 权限。

1. 下载CSV模板，或“加载现有价格”后导出表内价格，用Excel编辑；也可直接在表格内修改，或勾选多行统一设置某档价格。
2. 上传 .xlsx 或 .csv；XLSX只读取第一个工作表。每批1至500个商品，文件不超过5MB。超过500个请分批或缩小搜索范围。
3. 首行包含 SKU、A档价格、B档价格、C档价格、D档价格；商品名称仅作辅助，实际以SKU匹配的后台商品为准。
4. 空白价格保留原值；B/C/D填写“清空”会移除该档价格，该档客户将不能申购。A档不能清空。价格须大于0、最多两位小数。Excel的SKU列请设为文本以保留前导零。
5. 填写调价原因，点击“预览校验”，核对原价→新价，再确认整批保存。存在错误行不允许保存。

保存采用同一事务，任一商品价格较预览时变化、状态不满足或审计失败，整批回滚。逐商品记录前后价及操作人，汇总记录批次；不改变库存、客户余额、历史成交价和历史退回金额。

网络异常会在当前操作人本地保留原批次。使用“核对原批次结果”或“继续提交原批次”；需要改内容时先取消原批次，服务器确认取消后再重新预览。取消采用持久化回执，即使原请求迟到也不能覆盖价格；已保存的批次取消操作会返回已保存结果，不会假报取消或撤回价格。

接口：GET /pricing/prices/batch-items；POST /pricing/prices/batch-preview；POST /pricing/prices/batch；GET /pricing/prices/batches/:requestId；POST /pricing/prices/batches/:requestId/cancel。

复用既有四档价格字段及 operation_log，无新增数据库迁移。OMS新报价沿用现有按客户档位实时读取ERP的接口。
