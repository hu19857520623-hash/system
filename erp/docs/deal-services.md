# 成交服务

首次成交和再次成交共用 `erp/shared/deal-services.ts` 中的19项服务。每条成交只选择一项，用代码区分同名的 A1/B1。A5 为“跨境本土店（南非公司注册＋公户，XT 回款）”。

成交记录保存服务代码和成交时的名称，保留原有日期、金额、备注、附件和客户归属。选择货盘押金或首充服务仅登记成交，不触发资金入账；押金或充值到账继续走对应财务流程。

OMS 开户是单独操作：每次打开开户弹窗，客户类型和权限模板均为空，必须手动选择电商、货盘或混合类型；不再从新成交服务或旧店铺类型推断。后端缺少明确类型时也拒绝开户。

成交管理仍以客户为一行，展示其各条成交服务。服务筛选按代码、名称或历史类型匹配；与成交日期、状态组合时，条件必须命中同一条成交记录。详情展示完整历史。异步导出每条匹配成交一行，分别导出代码、名称、原成交日期、原金额和备注；超过现有导出行数限制时要求缩小范围。

旧“本土店/跨境店/海外仓”保留原文并显示历史类型，不自动转换服务代码。旧客户端暂可按原三个类型提交，新界面必须选择一个明确的服务代码。

## 上线

本次未执行生产数据库迁移或部署。上线前备份，单独应用并登记 `migrate_lead_deal_service.sql`，为 `lead_deal` 添加可空的 `service_code`、`service_name` 和代码索引，再重新生成 Prisma Client、构建和部署 ERP。线上历史迁移记录存在差异，不要重跑全部历史 SQL。

工作区仍有暂停的四档货盘价格草稿。发布本功能时须只包含成交服务的改动，不能把该草稿一并上线。
