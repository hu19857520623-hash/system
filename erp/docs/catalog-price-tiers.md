# 货盘商品四档售价

每个 SKU 分别设置 A、B、C、D 四个人民币金额，每个客户绑定其中一个档位。四档共用同一库存池，消费使用同一余额和信用额度。

## 使用方式

1. ERP 货盘库存先按原流程完成基础定价。
2. 在商品的“四档售价”列点击“设置四档价格”，逐项输入并填写调价原因。A 档沿用原售价，B/C/D 可以留空。
3. ERP 客户管理的“货盘价格档位”列为客户选择 A/B/C/D。
4. 客户刷新 OMS 货盘后看到自己的报价。未设置该档价格的商品显示未定价，不能购买；不会套用其他档位。

旧的基础定价、调价表单继续维护 A 档，不会覆盖 B/C/D 档。商品四档金额不要求按大小排列，也不使用折扣比例。

## 结算规则

- 报价档位以 ERP 客户主档为准。OMS 普通客户接口只使用登录客户身份，不接受自选其他客户或价格档位。
- 目录及单商品接口仅返回该客户的一档报价，不返回四档金额。
- 下单事务锁定客户和商品，重新读取档位、核对报价，并扣款与库存。切换档位或调价导致报价不同，要求刷新后确认，本次不扣款。
- 成交订单保存原单价、原总额和成交档位。已成交的原请求重试返回原单，后续切换档位不会造成重复扣款。退款沿用原购买单的金额。
- 四档调价和客户换档均记录审计，并核对保存前的旧值，防止过期页面覆盖他人的修改。

## 数据库与上线

本次代码尚未执行生产迁移或部署。上线前须备份，再应用该迁移并登记校验和，重新生成 ERP Prisma Client，构建和部署 ERP/OMS。线上历史迁移记录存在差异，不能盲目重跑全部历史 SQL。
