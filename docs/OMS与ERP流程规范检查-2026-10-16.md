# OMS 与 ERP 流程规范检查

检查开始日期：2026-10-16；最近更新：2026-10-22。任务仍在进行，本报告不代表全部按钮、角色和单据状态已经通过实测。

## 验收要求

1. 页面操作有明确的成功结果、中文失败说明及可恢复入口。
2. 创建、编辑、预约、审核等流程有适用的返回、取消、继续或下一步入口；不能把所有按钮机械地加上“继续”。
3. 保存、提交、撤回、重试的状态变化符合实际业务结果；接口失败不能显示成功，也不能将已提交的动作提示成未发生。
4. 已删除、无权限、无效链接、初始化失败及页面运行异常都有明确中文提示和返回路径。
5. 不展示原始英文网络异常、英文默认 HTTP 提示、英文校验错误、数据库异常或网关 HTML；保留中文业务细节、合法 SKU、单号及文件名。
6. 同一操作在不同角色、状态、成功/失败/取消分支下分别验证；没有运行证据的条目不能标成通过。
7. 用户确认的中转仓收货规则：良品与破损均计入采购单已收数量，破损单独记录、不增加可用库存。例如采购 10、良品 8、破损 2，应收齐 10、待收 0、库存增加 8。
