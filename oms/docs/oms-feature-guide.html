1. 系统定位与角色

OMS（Order Management System）是面向 Takealot 等平台的海外仓客户端：客户在系统中完成预约入库、预约发货、库存查询、编码绑定与费用管理；系统管理员维护账号、费率模板与地区规则。

角色说明典型能力
电商客户自有商品入库后，对接平台订单预约发货店铺、商品、入库、出库、条码绑定、账单
货盘客户在货盘选品申购，形成货盘库存后发货货盘选品、入库/出库、库存、账单
混合客户同时经营电商与货盘上述能力并集，库存分池查看
系统管理员运营后台全客户数据、账号权限、价格/地区模板

2. 首页看板 已有

入口：首页 / 欢迎页  |  权限：dashboard:read

功能说明

登录后的第一屏工作台，汇总账户与待办，并提供按权限显示的常用功能入口，减少在菜单中查找的时间。

主要能力

  • 欢迎横幅：展示账户余额、今日订单数、待处理异常数；客户侧显示客户代码、角色、默认仓库；管理员侧显示全平台单量与活跃客户数。
  • 常用功能：按权限展示快捷入口（预约入库、预约发货、库存查询、订单与出库、费用账单、消息中心）。
  • 待办事项：在途入库、待发货出库、库存预警、未读消息，点击跳转对应列表并带筛选。
  • 最近业务：最近入库、最近出库（单号 + 状态）；与「订单与出库」模块对齐，不再单独展示重复的「最近订单」。
  • 系统公告：展示重要/普通公告列表。
使用提示
管理员与客户看到的数据范围不同：客户仅本账户待办与单据；管理员可看全平台概况。

3. 库存查询与库存预警 已有

入口：库存 → 库存查询 / 库存预警  |  权限：inventory:read

功能说明

以仓库实物为准，分「自有库存 / 货盘库存」两池查询 SKU 各维度数量，并识别低库存与断货风险。

主要能力

  • 库存池切换：全部 / 自有库存 / 货盘库存（混合客户可同时查看双池）。
  • 状态 Tab：全部、低库存、缺货、有锁定、待上架。
  • 高级筛选：SKU、自定义编号、产品名称、EAN/条码、仓库、数量类型（可用/锁定/待上架/待出库/不良品/在途/已出库）及数量区间。
  • 列表字段：品名规格、实测尺寸与体积、SKU、自定义编号、仓库、库存来源、可用/待上架/待出库/锁定/在途/不良品/已出库、库存状态。
  • 预警规则：可用=0 且在途=0 → 断货；可用 < 安全库存 → 低库存。预警页默认聚焦低库存视图。
业务价值
客户可随时核对可发货数量与锁定占用，避免超卖；运营可按预警优先补货或催入仓。

4. 货盘选品与申购锁定 已有

入口：商品管理 → 货盘选品  |  权限：catalog:read / catalog:write（货盘 / 混合客户）

功能说明

货盘客户浏览可售货盘商品，按数量「申购并锁定」：从共享货盘可售库存扣减，计入本客户货盘锁定库存，并生成申购记录，供后续预约发货使用。

操作流程

  • 按品类浏览或按名称 / SKU 搜索货盘商品。
  • 查看价格、可售量、已锁定量、规格重量。
  • 填写申购数量，确认「申购并锁定」。
  • 系统生成申购单号，库存即时反映锁定结果。
  • 后续在「预约发货」中选择货盘库存来源出库。
适用角色
货盘客户、混合客户。纯电商客户默认无货盘权限；可由管理员升级为混合客户后开通。

5. 编码与绑定（平台商品条码） 已有

入口：商品管理 → 编码与绑定 → 平台商品绑定  |  权限：platform:read / platform:write；审核 code:approve

功能说明

将平台商品条码与仓库内部 SKU 建立映射，订单同步或出库扣库存时据此识别商品。系统不要求绑定 TSIN，以条码为主键信息。

主要能力

  • 状态 Tab：全部 / 待绑定 / 已绑定 / 条码不一致 / 待审核。
  • 新增 / 编辑绑定：选择平台与店铺，填写平台商品条码、名称、库存来源（自有/货盘），选择仓库 SKU；支持组合品（一行平台商品对应多行仓库 SKU × 数量）。
  • 有库存变更审核：已绑定且有库存时修改映射，进入「待审核」，管理员审核后生效。
  • 同步 / 导入入口：可模拟从 Takealot 拉取待绑定 listing，再完成仓库 SKU 映射。
关键字段说明
平台商品条码必填，绑定主依据（非 TSIN）
平台店铺Takealot / Shopify 等已连接店铺
仓库商品编码内部 SKU，可多行组合
库存来源自有库存 / 货盘库存
绑定状态待绑定 / 已绑定 / 待审核 / 条码不一致

6. 费用账单与账户充值 已有

入口：费用管理 → 费用账单 / 账户充值  |  权限：billing:read；充值 billing:recharge

费用账单

  • 展示账户余额、累计扣费、预扣笔数与预算使用情况。
  • 按月汇总仓储费、操作费、物流费。
  • 费用明细：日期、类型、关联单号、说明、金额；预扣类费用带标记，可追溯到出库单。
  • 计费模式说明：出库按 SKU 尺寸套用价格模板预扣；仓租按仓租模板按日计费。

账户充值

  • 展示对公转账 / 支付宝 / 微信等收款方式信息（可复制账号）。
  • 填写充值金额并确认，生成充值记录（充值编号、客户代码、金额、方式）。
  • 管理员可在系统中维护支付方式（启用、排序、银行信息 / 收款码等）。

7. 价格模板 / 仓租模板 / 地区模板 已有 管理员

入口：系统管理 → 价格模板 / 地区模板  |  权限：account:manage

7.1 出库价格模板

  • 维护多套价格模板，供客户账号绑定。
  • 操作费：每单 / 每件 / 每 SKU 行等维度。
  • 物流费：按地区（如 JHB / CPT / DBN）配置卡派（¥/m³）、快递（¥/kg）及最低收费。
  • 自提：按地区配置自提费（每单 + 每件等），另加操作费。
  • 客户预约发货时自动套用绑定模板试算并预扣。

7.2 仓租模板

  • 按体积（CBM/天）或件数（件/天）计费。
  • 可配置单价、每日最低消费、免租天数。

7.3 地区配送规则

  • 为各地区配置默认配送方式（卡派 / 快递）及启用状态。
  • 预约发货选择目的地区后自动带出默认配送方式；Takealot 入仓可按目的仓匹配地区。

8. 账号管理与权限分配 已有 管理员

入口：系统管理 → 账号管理  |  权限：account:manage / account:assign / account:disable

功能说明

统一管理电商 / 货盘 / 混合客户账号：查看联系信息与状态，分配模块权限，绑定价格模板，支持业务类型升级与账号禁用。

主要能力

  • 账号列表：客户代码、类型、联系人、邮箱、权限数量、价格模板、启用状态、最近登录。
  • 权限分配：按模块勾选（看板、出库、货盘、商品与编码、入库、库存、物流、退件、费用、店铺、报表）；可一键套用电商 / 货盘 / 混合默认模板。
  • 业务升级：货盘 → 混合（开通电商）、电商 → 混合（开通货盘）；历史库存来源标记保留。
  • 价格模板绑定：为客户指定出库试算所用费率模板。
  • 启用 / 禁用：欠费或违规账号可一键禁用。

9. 预约发货 · 费用预扣试算 已有

入口：出库 → 预约发货  |  权限：outbound:read / outbound:write

功能说明

客户创建出库预约时，系统根据绑定的价格模板、目的地区、配送方式及 SKU 长宽高，自动试算操作费与物流费，展示预扣合计与当前余额；提交时锁定库存并预扣费用，余额不足则拦截。

操作要点

  • 选择发货来源：平台订单 / 货盘分销 / 手工录入。
  • 选择仓库、目的地区、配送方式（卡派 / 快递 / 自提等）。
  • 添加出库明细（SKU 与数量）。
  • 查看费用试算分项（模板名、体积 m³、重量 kg、各费用行）。
  • 确认提交：预扣成功并锁定库存，可在「订单与出库」中跟踪状态。
说明
「预约发货」整页仍在持续完善（如附件落库、送仓日等）；其中费用预扣试算与锁库存已作为核心能力落地，故纳入本「已有」介绍。

10. 角色权限与数据隔离 已有

系统按角色控制菜单与路由访问，并按客户维度隔离业务数据。

  • 权限控制：每个菜单/路由绑定权限码；无权限不展示、不可进入。
  • 数据范围：客户账号仅可见本 customerId 下的订单、库存、入库/出库、绑定等；管理员可查看全平台，并可用客户筛选器切换。
  • 库存可见性：混合客户可同时查看自有与货盘库存池；货盘废弃 SKU 等对客户侧有额外过滤。
  • 演示切换：顶栏可切换系统管理员 / 电商 / 货盘 / 混合角色，便于验收不同视角。
