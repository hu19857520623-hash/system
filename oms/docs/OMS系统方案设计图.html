OMS 权限与业务模式设计图

系统管理员统一分配权限 · 电商 / 货盘 / 混合三类客户 · 发货来源与库存来源区分

权限
角色

系统管理员

  • 创建 / 维护客户账号（电商 / 货盘 / 混合）
  • 按模块勾选分配权限
  • 套用「电商」「货盘」「混合」模板
  • 启用 / 禁用客户账号
  • 查看全部客户数据（监管）
账号管理 权限分配 禁用账号

电商客户

  • 绑定 Takealot / Shopify 店铺
  • 平台订单同步后在 OMS 预约发货
  • 使用自有库存履约出库
  • 发货来源标记为「平台订单」
  • 权限由管理员分配，无货盘选品
订单店铺 预约发货自有库存

货盘客户

  • 在 OMS 货盘选品、购货入库
  • 使用货盘库存在 OMS 预约发货
  • 发货来源标记为「货盘分销」
  • 库存查询、物流追踪、费用账单
  • 权限由管理员分配，无订单店铺
货盘入库 预约发货货盘库存

混合客户

  • 同时经营自有电商与货盘分销
  • 平台订单 + 货盘分销均可预约发货
  • 自有库存与货盘库存分池管理
  • 发货来源：平台订单 / 货盘分销 / 手工
  • 套用混合模板或管理员按需勾选
订单货盘 双库存全发货来源
