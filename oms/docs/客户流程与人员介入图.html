表1 · 客户环节 × 我方介入矩阵

必须介入 客户无法自行完成，需我方处理后方可继续； 视情况介入 正常流程自动，仅异常时人工； 全自动 无需人员。

客户环节（OMS） 客户操作 介入类型 我方角色 介入动作 产出/闭环
店铺管理 绑定 Takealot/Shopify、开启订单同步 视情况 客服 API 授权失败、Webhook 不通时协助联调；同步异常手动重试 店铺状态「已连接」，订单可自动拉取
我的商品 创建产品 → 保存并审核 必须介入 产品开发 / 客服 审核申报品名、重量尺寸、含电/液体/证书等合规项 状态变为「可用」或「审核不通过」并注明原因
编码管理 绑定 990 码、自定义码；有库存时申请变更 必须介入 客服 / 仓库主管 审批编码变更申请，版本化停用旧码 新编码生效，PDA 可正确解析
创建入库单 填写头程信息、SKU 明细 → 提交并审核 必须介入 客服 → 仓库主管 客服预审单据完整性；主管分配收货任务 入库单进入「在途/待收货」
入库收货 跟踪入库状态（只读） 必须介入 入库员 / 仓库主管 PDA 扫箱唛收货上架；差异时主管确认 「收货完成 / 上架完成」，库存可见
订单管理 查看订单、筛选、导出；异常单点击处理 视情况 客服 同步失败重试；地址异常联系客户修正；缺货协调补货或拆单 订单恢复「待发货」或标记取消
发货出库 创建出库单、上传外箱标/标签 必须介入 仓库主管 / 拣货员 锁库存后分配波次；拣货、复核、打包、贴标、出库确认 物流单号回传，订单「已出库」
库存查询 查可用/锁定/在途库存 全自动 — 仓库作业回传后自动更新；低库存仅系统预警 客户自助查看，无需工单
退件管理 创建退件单、填写 RMA/跟踪号 必须介入 客服 / 仓库 客服确认退件策略；仓库收货质检，决定上架/退回/销毁 退件单「已完成」，库存或费用调整
费用账单 查看明细、在线充值 视情况 财务 银行转账充值需财务核实到账；账单争议核对仓租/操作费 余额更新，可继续发货
原则：客户侧 OMS 负责「提需求、看状态、处理可自助的异常」；凡涉及实物移动、合规审核、资金确认、跨系统同步补偿四类事项，必须由我方对应角色介入，客户无法跳过。
